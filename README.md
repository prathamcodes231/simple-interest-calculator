
# Simple Interest Calculator

## Description
A simple interest calculator that calculates the interest earned on a principal amount over a given period at a specified rate of interest.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal Amount
- Rate of Interest
- Time Period

## Output
- Simple Interest
- Total Amount (Principal + Interest)
