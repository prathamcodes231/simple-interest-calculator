# Contributing Guidelines

Thank you for your interest in contributing to the Simple Interest Calculator project!

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork this repository.
2. Create a new branch for your changes.
3. Make your improvements or fix any reported issues.
4. Test your changes to ensure everything works correctly.
5. Submit a Pull Request with a clear description of your changes.

## Reporting Bugs

If you find any bugs or errors, please report them by creating a GitHub Issue. Include a clear explanation of the problem and steps to reproduce it.

## Suggestions and Improvements

Suggestions for new features, improvements, and documentation are always appreciated.

## Code Guidelines

- Write clean and readable code.
- Use meaningful variable names.
- Add comments wherever necessary.
- Test your code before submitting changes.

Thank you for helping improve this project!
